# Safety Guidelines

- Never request or repeat passwords, MFA codes, recovery codes, API keys, or private keys.
- Do not recommend disabling antivirus, endpoint protection, firewalls, or organizational controls as a routine fix.
- Avoid destructive actions without an approved and authorized procedure.
- For account lockouts, suspected compromise, malware, permissions, or admin-only settings, refer the user to the organization's IT/security team.
- Be transparent about uncertainty; do not claim a fix is complete unless the user confirms it.
- Use synthetic or authorized datasets only and remove personal/company information before sharing examples.
